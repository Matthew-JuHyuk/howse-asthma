# 오늘 모델·사용량 배분 계획
공식OpenAI문서확인2026-10-22. 아래비율/토큰범위는프로젝트운영제안이며계정의정확한남은한도나예측아님. 현재남은사용량을조회하지않았고API요금과ChatGPT/Codex구독제한은같지않다.

## 권장모델
| 작업 | 권장 | 사용 원칙 |
|---|---|---|
| 앱코드감사·음성/데이터/PDF통합·QA | GPT-6.1 Sol Medium | 주력. 여러파일복잡작업과비용균형 |
| 파일정리·fixture형식변환·자막타임코드·반복체크 | GPT-6 Luna High | 정확한입력/스키마주어진작업만 |
| 근본원인불명/설계충돌/최종중요감사 | Astra Light/Medium | 좁은증거패킷으로한정. 전체재설계반복안함 |
| 영상구성/편집지시·실제캡처검수 | GPT-6.1 Sol Medium | 컷단위요청, 실제미디어첨부 |
전부Astra를쓰거나전부Luna로전환하는것보다재작업까지고려한조합. 모델을이세션에서변경한것은아님. 기능/모델선택기는계정·클라이언트·rollout에따라다름. 사용가능하지않으면현재보이는Sol계열로시작하고설정에없는이름을억지로지정하지않는다.

## 남은 예산 운영안
남은작업예산을100으로놓을때 구현/통합65, 영상제작20, 막힌문제·최종검수15를초기배분. 리서치는이자료의미디어접근한계에서멈추고추가검색무한반복안함. 실제앱핵심이미통과하면구현분을영상으로옮김.
토큰은모델/추론/도구/재입력/캐시와repo크기에좌우되어한도퍼센트로환산불가. 단순텍스트입출력의초기계획범위: 감사3~6k, 모듈구현20~45k, seed/QA10~20k, 영상정리/편집8~15k, 예비5~10k = 약46~96k. 숨은추론·도구대량출력·긴repo재입력은별도이므로이숫자로Plus완주를보장하지않는다. 동영상/이미지입력도별도사용량을발생시킬수있음.
각단계후클라이언트실제사용량과남은작업을확인. 2회원인불명실패면같은전체지시반복대신오류1개/관련파일/최소로그만상위모델로. WBS/실패기록/정책문서전체를매번프롬프트에복붙하지말고state.md참조. 전체영상전프레임덤프보다구간별contactsheet와전환부검증. 100줄넘는성공로그·파일전체출력제한. 테스트통과후코드변경없이전체재실행반복금지.

## 오늘 완료 순서와 시간 관리
1. 감사와P0확정→2. 두경로/기록/음성 실제완주→3. seed·APK검증→4. 독립클립촬영→5.170초검토본→6.실제음성/자막/최종검수.
실제코드감사전완료시간확약금지. P0기능막히면센서/집계/추가OS는하지않음. 카메라/더빙/녹화는사람과도구시간이필요해토큰만으로해결되지않음. 실제촬영파일/저장소없는현재환경에서앱또는영상완성을주장하지않음.
