## 자동 검사와 실기기 테스트 구분

이 결과는 계정·DB 초기 상태·원본 다운로드 검사다. 사진 OCR/ASR/AI 추출 정확도, 공유창·알림·잠금 동작은 실제 기기에서 아직 확인하지 않았다. 상세 수동 항목은 `test_scenarios_ko.md`를 따른다. APK 빌드 성공은 해당 기능 테스트 통과를 뜻하지 않는다.
