## 실행 방식
기존 파일명 Cursor_Sprint10_Prompt.txt는 Codex 호환 통합 지시문이다. 최초에는 그 파일과 v1.5 요구사항을 한 번만 제공한다. 아래 단계 프롬프트는 작업 분리/재개용이며 매 단계 전체 명세를 재출력하지 않는다. 한 세션에서 계속하면 반복 붙여넣기 불필요. 각 단계 말미 docs/sprint10/state.md에 완료/미검증/변경파일/검증명령/다음작업을 갱신하여 다음 모델·세션이 재사용한다. 모델은 사용자가 선택하며 자동 subagent/병렬 모델 작업을 시작하지 않는다.
저장소에서 사용자가 구현 시작을 명시했을 때 00~40은 연속 진행할 수 있다. 실제 촬영·편집은 해당 디바이스/도구/녹화파일이 있어야 하며 없는 자료를 가짜 앱 화면으로 대체하지 않는다. 게시/메일/공모 제출은 별도 명시적 지시 후.
