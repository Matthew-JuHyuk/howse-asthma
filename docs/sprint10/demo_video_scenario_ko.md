# Sprint 10 데모 시연영상 시나리오 — 한글

이 문서는 **촬영 순서·대사·편집 계획**이다. 테스트 절차·기대값은 [기능 테스트 시나리오](test_scenarios_ko.md), DB 등록 여부는 [DB 점검 결과](db_demo_audit_ko.md)를 참조한다. 영상은 테스트 일부를 골라 구성한다.

## 인물과 이야기

스페인어가 편한 Rosa(38)는 아들 Diego(14)의 야간 기침과 축구 중 불편을 기록한다. 기존 처방·과거 방문·검사 결과가 흩어져 있어 진료팀에 무엇을 보내야 할지 모른다. CoverNote에서 출처와 누락 자료를 확인해 영문 준비 요약을 만든다.

A는 **최초 요청 전**, B는 **앱 밖에서 이미 서류 부족으로 거절된 경우**다. 같은 가족의 두 대체 상황이다. 앱에서 신청 직후 거절된 것으로 연결하지 않는다. 앱이 치료나 보험 승인을 결정한다고 설명하지 않는다.

## 촬영 준비물

- 최신 APK와 `diego@example.com` 계정, Spanish 언어, Diego 대상. 비밀번호는 제공된 데모 비밀번호 사용.
- **04 PDF:** 포털에서 받은 검사 결과 역할. 폰에 복사해 본편에서 업로드.
- **05 PDF 인쇄본:** 종이 검사 결과 역할. 기본 카메라 촬영 후 JPG 입력 보조 컷. 04와 같은 검사이므로 저장하지 않음.
- **03 PDF 인쇄본:** 우편 거절 통지 역할. B에 원본이 이미 있어 사진 입력 보조 컷은 후보 확인 후 취소.
- **01 처방/02 방문:** DB에 준비된 보조 문서. 앱에서 바로 원본을 열어 보여줌.
- 파일 위치: `output/pdf/sprint10-demo/`. 모든 문서 1페이지, SAMPLE 표시. 첫 동의·마이크 권한은 실제 화면에서 확인.

## 종이 입력 보조 컷 — 별도 테이크

**종이 검사 약 15초(TC-06):** 05 인쇄본 → 휴대폰 기본 카메라로 전체 페이지 촬영 → 준비 화면에서 JPG 파일 선택 → 420 cells/uL 원문 확인 → 취소. 자막 “종이 자료도 사진으로 추가”. 준비 화면에 카메라 버튼이 있는 것처럼 편집하지 않는다.

**우편 통지 약 15초(TC-09):** 03 인쇄본을 봉투 옆에 놓음 → 촬영 → B에서 사진 파일 선택 → 거절 사유/두 기한 후보 확인 → 취소. 기존 B 통지를 중복 입력하거나 새 보험 결정으로 설명하지 않는다.

## 편집·재촬영

- 먼저 저장하지 않는 보조 컷을 찍고, 검사 저장/근거 연결은 본편 마지막 테이크에 한다. 04/05는 같은 검사이므로 한 경로만 저장한다.
- 실제 로딩을 짧게 편집할 수 있으나, 모델이 내놓지 않은 결과나 실제로 하지 않은 전송·승인을 만들지 않는다.
- 스페인어 음성에 한국어 자막, 준비 PDF는 영문으로 보여준다. 시나리오 설명은 한글이다.
- 지역 환경은 실제 조회가 성공했을 때만 보조 컷으로 사용한다. 가짜 대기질·증상 인과관계는 없다.
- 실기기 촬영/사용성 검증은 별도다. 본 문서는 촬영 대본이며 녹화 완료 보고가 아니다.
