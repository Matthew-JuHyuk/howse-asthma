# Sprint10 음성 입력·기록 동선 수정 (1.0.15)

## 사용 흐름

- **기록 탭**: 기록 대상 선택 → 오늘 약 사용 버튼 → 저장 알림. 정기 복약과 필요 시 약/흡입기 사용을 접힌 메뉴 없이 노출한다. 달력에서 이전 기록을 보고 있더라도 버튼은 명시된 **오늘**에 저장하고 오늘 날짜로 돌아온다.
- **중앙 마이크**: 질문·예시 → 말하기 또는 직접 입력 → AI가 증상·약 사용 등을 분류 → 사용자 확인 → 저장. 종류 선택 버튼을 제거했다. 종류를 미리 지정하는 값도 AI에 전송하지 않는다.
- **케이스**: 필요한 서류와 이력 연결 → 연결한 기록 검토 → 전달 자료 만들기. 케이스의 일일기록 입력 카드와 복약 버튼을 제거했다. `연결한 기록`에는 해당 사람의 이 케이스에 실제 연결된 이력만 표시한다.
- **데모·설정**: 데모 시작 버튼 사이 16dp, 사례 카드 사이 20dp, 주요 구역 사이 24~28dp. 설정의 계정 버튼과 동의 항목 여백을 확대하고 하단 OS 안전 영역을 반영했다.

## 음성 실패 대응

이전 코드는 온디바이스 인식기가 존재하면 언어 모델의 설치 여부와 관계없이 우선 사용했다. Android 문서는 언어 데이터 미설치 시 `ERROR_LANGUAGE_UNAVAILABLE`이 발생할 수 있음을 설명한다. 기기 로그가 없으므로 사용자 기기에서 발생한 원인이라고 단정하지 않는다.

이번 수정은 기본 음성 서비스 사용, 언어 코드의 지역 지정, 서비스·언어 초기화 오류 시 시스템 음성 입력 화면으로 대체 실행, 종료 시 요청 취소, 대기 시간 제한을 포함한다. 사용자의 취소는 실패 경고로 표시하지 않는다. 권한 거부는 앱 설정 버튼을, 네트워크/서비스 실패는 원인별 안내와 직접 입력을 제공한다. 입력한 글은 유지한다.

참고: [Android SpeechRecognizer 공식 문서](https://developer.android.com/reference/android/speech/SpeechRecognizer).

## 기록 데이터 규칙

- 선택한 사람의 사용 사실만 저장한다. 약 이름·용량은 자동으로 추정하지 않는다.
- 버튼 처리 중 중복 실행을 막는다. 같은 날 정기 복약이 이미 있으면 추가 사용 여부를 확인한다.
- 저장 직후 취소할 수 있다. 오프라인이면 기존 동기화 대기 기능을 사용한다.
- 기존 기록이나 데모 DB를 덮어쓰지 않았다. 서버/API 변경이 없어 이번 버전은 앱 업데이트로 반영된다.

## 검증

- 음성 입력 결과의 편집, 권한/연결/서비스 실패 및 취소 시 입력 보존, 저장 전 확인 검사.
- 복약 바로 기록의 대상 분리, 미지정 약·용량 보존, 중복 방지, 취소 검사.
- 영어·한국어·스페인어 320dp/글자 200%, 기존 9개 언어 화면 탐색 회귀 검사.
- 실제 Flutter 위젯을 렌더링해 안내형 입력, 복약 버튼, 데모 화면 간격 확인.
- 실제 Android 기기는 연결되어 있지 않다. 이 검증은 실제 마이크 인식 성공을 보증하지 않으며 사용자 Galaxy에서 재확인이 필요하다.

## 설치 후 확인

1. 중앙 마이크 → 말하기 시작 → “아침에 흡입기를 썼고 어젯밤 기침이 났어요.” → 편집 가능한 글이 나타나는지 확인한다.
2. 내용 확인에서 증상과 약 사용으로 분류되는지 보고 저장한다.
3. 기록 탭에서 사람을 확인하고 정기 복약 또는 필요 시 사용 버튼을 누른다. 오늘 달력과 일일 목록에 반영되는지 확인한다.
4. 케이스의 자료 연결에는 입력 기능이 없고, 연결한 기록 탭에는 선택한 자료만 보이는지 확인한다.
